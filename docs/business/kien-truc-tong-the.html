00-overview Roadmap
Chapter 0 · Overview · main branch, 2026-10-14

The Physical AI that really does things, safely by design.

AI that acts for real: it switches relays, opens valves, locks doors. Safe by design: the model only proposes and the gate decides; no token, no action; when in doubt, block (Q-82).

Just say it

  • "Turn on the porch light."
  • "Let the guest in."
  • "Water the plants at 6."
You speak, NeuroClaw proposes, and the NeuroEdge box decides before anything touches a device.
You: let the guest in Box: ASK · checks with the owner first Owner: yes → ALLOW · recorded in trace.v1

Chapter 8 · What everything else relies on

Three guarantees

details: threat_model
🚫

No shortcuts

  • Direct calls to @action or digital.out(): denied
  • Forged, spent or expired tokens: denied
  • Every denial is traced
✋

When in doubt, block

  • fail: closed by default
  • Missing or stale facts: no ALLOW
  • Commands to the safe state are always allowed
🔁

One contract everywhere

  • Resolution is a pure function
  • On the chip: no JSON, no allocation
  • verify compares verdicts across targets

Chapter 12 · Checked against the code

Common misconceptions

NeuroClaw drives the lights and doors itselfNeuroClaw only calls the box's MCP tools; the gate decides.
It is safe because NeuroClaw has no shellQ-80 restored the shell to match PicoClaw, with risk labels. Safety comes from the gate and a separate user account.
The gate engine issues tokensTokenLedger in actions/ issues them.
A token is a cryptographic signatureIt is a random nonce in the process's ledger, used once per pin.
Network down → instant BLOCKIt falls back to the local command grammar first; it blocks only when no fallback exists.
esp32s3 already drives devicesThe gate runs on QEMU; it does not drive pins yet (TSK-S4-01).
Muse Bridge and a plugin marketplace existMuse left the roadmap (Q-77). The only plugin so far is an Actuator: Home Assistant.
